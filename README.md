# 🤖 AI-Agent-CLI (Gemini SDK)

**AI-Agent-CLI** es una herramienta de línea de comandos que permite interactuar directamente con el modelo **Gemini** de Google mediante su **SDK oficial**.  
Con esta aplicación, puedes enviar mensajes y obtener respuestas inteligentes sin salir de la terminal.

---

## 🚀 Características

- 💬 Interactúa con **Gemini AI** desde la terminal.
- ⚙️ Basado en el **Gemini SDK** oficial de Google.
- 🧠 Respuestas en lenguaje natural.
- 🪶 Interfaz minimalista, rápida y fácil de usar.
- 🔐 Soporte para claves de API mediante `.env`.

---

## 🧩 Requisitos previos

Antes de comenzar, asegúrate de tener:

- **Node.js** (v18 o superior)
- Una **API Key de Gemini** (puedes obtenerla en [Google AI Studio](https://aistudio.google.com/app/apikey))
- **npm** o **yarn** instalado
